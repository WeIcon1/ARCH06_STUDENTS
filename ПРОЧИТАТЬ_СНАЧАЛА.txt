ATLAS UI — практическая работа № 6

Структура подготовлена по примеру на скриншоте GitHub.

проект/ — готовые исходники, CSS, JS, тесты и README.
Материалы/ — отчёты, аудит, матрица сценариев, скриншоты, эталонные изображения.

ЗАПУСК:
1. Установить Node.js 18 или новее.
2. Открыть папку «проект» в Visual Studio Code.
3. В терминале выполнить npm install, затем npm run dev.
4. Открыть http://localhost:5173.

ПРОВЕРКИ: npm test.
