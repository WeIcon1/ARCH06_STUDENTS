# Atlas UI

Учебный стенд практической работы № 6 по компонентной архитектуре CSS. В нём представлены семь семейств компонентов, две темы и отдельный виджет подрядчика.

## Запуск

Нужен Node.js 18 или новее. Выполните из каталога проекта.

```sh
npm run dev
```

Стенд доступен по адресу `http://127.0.0.1:5173`.

## Проверки

```sh
npm test
npm ci
npx playwright install chromium
npm run test:e2e
```

Для запуска браузерных тестов в установленном Chrome задайте `ATLAS_BROWSER_CHANNEL=chrome`. Переменная `PORT` меняет порт сервера и адрес в Playwright.
