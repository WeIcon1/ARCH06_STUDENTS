# Брифинг: merge incident ARCH-07

Две команды объединили интерфейс «Atlas UI» с подрядным виджетом. Продуктовая команда требует оставить пользовательский сценарий и весь набор семейств компонентов.

## Роли

- Frontend Architect: отвечает за план слоёв, границы компонентов, документ ADR.
- Debug Investigator: проводит DevTools-трассировки cascade/layers/computed.
- A11y & QA Engineer: проверяет клавиатуру, темы, viewport, регрессии и тесты.

Все три роли могут быть выполнены одним студентом. В командах рекомендуется смена ролей каждые 40 минут.

## Изменения, которые запрещено применять как «решение»

- удалить `legacy.css` и `legacy-widget`, чтобы конфликты исчезли.
- скрыть горизонтальный overflow у `body` без исправления размеров.
- добавить новые `!important`, многократные ID в селекторах.
- отключить тесты/валидацию/состояния компонентов.
- сделать `display:none` для checkbox переключателя.
- переписать приложение на сторонний UI framework, исключив разбор каскада.
- молча менять формулировки критериев приёмки.

## Независимое изменение на защите

Преподаватель выбирает одну задачу из списка.

- Новый тип опасной метки.
- Внешний контейнер с другим font-size.
- Изменение порядка слоёв с анализом.
- Кнопка на всю ширину только в карточке при 375 px.
- Размер уведомлений в тёмной теме.
- Переключатель, управляемый только клавиатурой.
- Новый статус карточки.
- Принудительный reduced-motion.

## Важные термины

`@layer`, normal/important origin, specificity, `:where()`, `:is()`, `:has()`, component contract, regression test, native `disabled`, `focus-visible`, semantic tokens, vendor isolation.
