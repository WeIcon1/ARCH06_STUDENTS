# ADR 001 Управление каскадом

Статус - принято. Дата - 18.11.2026.

## Контекст

Стили подрядчика вне слоя захватывали фон кнопок. Служебный класс `.is-danger` связывал оформление трёх семейств. Вложенный текст одновременно зависел от карточки и уведомления.

| Альтернатива | Польза | Риск | Решение |
|---|---|---|---|
| Единый CSS-файл | Простой запуск | Порядок блоков и специфичность трудно контролировать | Отклонено |
| БЭМ и регламент | По имени виден владелец правила | Дисциплина имён не задаёт приоритет чужих правил | Использованы локальные классы |
| Слои, токены и контракт | Явные приоритеты и смена темы через токены | Каждый CSS-импорт требует проверки области | Принято |
| CSS Modules | Локальные имена при сборке | Нужен сборщик, порядок каскада остаётся отдельным решением | Отклонено для этого стенда |

## Правила

| Слой | Ответственность |
|---|---|
| reset | Box sizing и исходные отступы документа |
| legacy | Ограниченные виджетом правила подрядчика, включая подслой `legacy.vendor-v2` |
| tokens | Цветовые роли, темы, размеры, фокус и движение |
| base | Общая типографика, каркас и резервный `:focus-visible` |
| components | Внешний вид, слоты, варианты и размеры |
| states | Нативные и управляемые состояния |
| utilities | Узкие адаптивные правила и режим reduced-motion |

Порядок обычных объявлений от меньшего приоритета к большему - `reset → legacy → tokens → base → components → states → utilities`. Все импорты именованы. Корень компонента обычно выбирается одним классом. Состояние добавляет псевдокласс или атрибут, слот имеет своего владельца. `:where()` обнуляет вес границы подрядчика и сбросов. ID используются для связей и JS. Для тем меняется `data-theme` на `html`, общие семантические токены наследуются.

## Публичные классы и состояния

| Семейство | Корень и контракт |
|---|---|
| Кнопка | `.ui-button` плюс `--primary`, `--secondary`, `--ghost` или `--danger`. `--sm`, базовый md либо `--lg`. Нативный `disabled` для `button`, состояния `:hover`, `:focus-visible`, `:active`. |
| Поле | `.ui-field`, прямые `label` и `input` или `textarea`, слоты `__hint` и `__error`, `--full` в сетке. Для обязательных полей JS управляет `aria-invalid` и `aria-describedby`. |
| Карточка | `.ui-card`, `--featured`, прямые слоты `__title`, `__description`, `__meta`, `__action`. Вложенные семейства подключаются со своими классами. |
| Метка | `.ui-tag` плюс `--neutral`, `--success`, `--warning` или `--danger`. Статический текст. |
| Уведомление | `.ui-alert` плюс `--info`, `--success`, `--warning` или `--danger`. Слоты `__content`, `__title`, `__message`, необязательный `__dismiss`. Текстовой области назначается `role=status` или `role=alert`. |
| Переключатель | `.ui-switch` как `label`, затем внутри неё checkbox перед `__track` с `__thumb`. Нативные `checked`, `disabled`, `:focus-visible`. |
| Диалог | `dialog.ui-dialog` с `aria-labelledby`, `__head`, `__title`, `__description` и `__actions`. `showModal()` и `form[method=dialog]` управляют открытием и закрытием. |

Цвета настраиваются через тему и токены в `css/tokens.css`. Например, `--color-accent` и `--color-focus` переопределяются для тёмной темы. Переменные `--_button-*` и `--_alert-*` обслуживают реализацию вариантов. Стили карточки применяются к прямым слотам. У `__action` включается ширина 100% при ширине области содержимого до 400 px.

## Компромиссы

- Слои управляют приоритетом. Глобальный селектор всё равно затронет элементы, для которых позже не назначено то же свойство. У нового импорта проверяются и слой, и область совпадения.
- Контракты рассчитаны на один вариант и один размер за раз. Для ссылки, визуально похожей на кнопку, предусмотрено обычное ссылочное действие. Нативное `disabled` применяется к `button`.
- Проверки в Chromium воспроизводят каскад и доступную клавиатурой навигацию. Реальные объявления экранных дикторов и различия браузеров требуют отдельной проверки.

## Контрпримеры

1. Подрядный фон с `!important` переживёт обычные правила библиотеки даже в раннем слое. Важные объявления в именованных слоях при конфликте сортируются в обратном порядке.
2. Поздний слой не спасает унаследованный цвет уведомления, если селектор карточки назначает значение самому абзацу. Прямые слоты устраняют такое совпадение.
